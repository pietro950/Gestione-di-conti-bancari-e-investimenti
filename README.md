# Gestione-di-conti-bancari-e-investimenti
App Windows Forms in C# per gestire conti bancari e di investimento. ContoBancario gestisce saldo, depositi e prelievi; ContoInvestimenti lo estende, permettendo di investire in vari asset (overloading di Investi) e calcolando il valore totale con i rendimenti. I dati si salvano in JSON o SQLite; il form permette creazione, caricamento e rimozione.
